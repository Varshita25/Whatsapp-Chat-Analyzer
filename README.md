# 📊 WhatsApp Chat Analyzer

A Streamlit app to analyze your WhatsApp chats and visualize:

- 📈 Total messages, words, media, and links
- 🧑‍💬 Most active users
- 🌐 Word cloud and most common words

---

## 🚀 How to Use

1. Export your WhatsApp chat (.txt) **without media**
2. Run the app:

```bash
streamlit run app.py
